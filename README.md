# ChitMate React

This folder contains a React version of the ChitMate dashboard.

It runs directly in a browser using the React and ReactDOM UMD builds from unpkg. Open `index.html` while connected to the internet, or move this folder into a standard Vite project when Node.js/npm is available.

The main React entry point is `app.js`. It uses React components and hooks for navigation, activity state, and the add-member modal.
